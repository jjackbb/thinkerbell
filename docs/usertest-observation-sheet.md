> **로그는 어디서 멈췄는지만 알려주고, 왜 멈췄는지는 못 알려준다.** 이 종이가 '왜'다.

```
계정 번호  test [____]        시작 시각 [__:__]        진행자 [________]
```

## 진행 규칙 (진행자용 — 딱 이것만)

- **설명하지 않는다.** 물어보면 "어떻게 하고 싶으세요?"로 되돌린다.
- 멈춰 있을 때만 한 마디: **"지금 뭘 하려고 하셨어요?"**
- 5분이 지나면 중간이라도 멈춘다. 다 못 해도 그게 데이터다.
