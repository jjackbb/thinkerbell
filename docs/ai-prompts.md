# AI 코드 수정 안내

정책은 [PLAN](../PLAN.md), 실행 상태는 [인수인계](plan-execution/README.md)입니다. [정리 전 안내](../archive/2026-09-30/current-docs-before-cleanup/docs/ai-prompts.md)는 과거 코드 상태를 설명하며 현재 구현 지시가 아닙니다.

## 파일과 신뢰 경계

| 파일 | 역할 |
| --- | --- |
| `frontend/src/lib/prompts.ts` | 공통 프롬프트 빌더·고정 인사·종결 기호. 서버도 이 모듈을 import함 |
| `frontend/src/components/AIChatView.tsx` | 스트림 표시·답변 완료/저장 결과 분리·재시도·마무리 |
| `frontend/src/App.tsx` | 모드/사연 진입·화면 상태 연결 |
| `frontend/src/lib/aiPersonas.ts` | 방 생성 서버 API, 소유 대화 조회 등 브라우저 요청 |
| `frontend/src/lib/aiQuota.ts` | 서버 횟수 상태 조회. 남아 있는 legacy helper를 현재 승인된 직접 쓰기 경로로 해석하지 않음 |
| `backend/app.ts` | 인증·소유권·보존 맥락·포텐스 요청·저장/차감·평가·신고 경로 |
| `backend/potensStream.ts` | 명시적 공급자 완료·비어 있지 않은 응답 확인 |

## 현재 계약

- AI 공급자는 포텐스 단독이며 Gemini·모의 답변 fallback은 사용하지 않는다. 답변을 지어내 성공처럼 표시하지 않는다.
- 서버가 사연 권한·소유 대화·저장 맥락을 확인한다. 브라우저의 프롬프트·검사 결과만 신뢰하지 않는다.
- `text` 뒤 `provider_done`은 정상 답변 완료, `done/persisted`는 저장 완료다. `ai_chat_turn1/turn3`은 정상 답변 완료를 세고 저장 결과는 별도로 보낸다.
- 부분·빈 응답·완료 신호 없는 종료는 성공 턴이 아니다. 저장 실패에도 완료 답변은 집계하며 미차감·입력 보존·새 답변 재요청을 유지한다.
- 횟수의 server/legacy 모드는 서버 설정에 따른다. 새 규칙은 요청일 한국 날짜·남의 사연 신규 하루 3회·첫 정상 저장 시 차감·실패 반환이다. 전환 이전 방 무료 이어하기와 본인 사연 무차감을 유지한다.
- 마무리는 대화를 보존한다. 두 모드 모두 정상 저장 답변 뒤 선택형 5점 평가를 제공하며 평가값은 GA4에 보내지 않는다.
- `SIM_END`의 역할극 종결과 사용자 도움 평가·실제 갈등 해결 성과를 구분한다. 기존 프롬프트 난이도는 임의 변경하지 않는다.
- 비공개 타인 사연은 새 방 생성 차단, 이미 소유한 대화는 보존 맥락으로 이용한다. 성인 기능은 보류다.

## 수정 후 확인

변경 영향에 맞춰 타입·빌드·해당 스트림/저장 경로를 확인한다. 작은 가역 수정에 새 테스트를 만들거나 이미 통과한 검사를 반복하지 않는다. 실제 AI/DB·오류 주입·브라우저·GA4 수신 결과를 구분한다.
