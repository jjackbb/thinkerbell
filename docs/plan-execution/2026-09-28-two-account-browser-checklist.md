# 지정 A·B 계정 검증 범위

아래는 최신 인수인계에 기록된 결과입니다. 원격 재조회 시각을 의미하지 않습니다. [과거 절차·실행 원문](../../archive/2026-09-30/current-docs-before-cleanup/docs/plan-execution/2026-09-28-two-account-browser-checklist.md)을 보존했습니다.

| 범위 | 기록된 결과 | 해석의 한계 |
| --- | --- | --- |
| 소유 확인·가입·로그인 | A/B 메일 도착·한국어·Preview 복귀/가입·분리 로그인 확인, A 기존 가입 registered 확인 | 실제 메일함 계정의 기술 시험. 사용자 만족도 아님 |
| 비밀번호 재설정 | A 실제 메일·공개 폼 복귀 확인; 저장·새 비밀번호 재로그인은 사용자 완료 보고 | AI가 재설정 PUT을 직접 관찰했다고 쓰지 않음 |
| 사연·투표·댓글·공감 | 핵심 생성/변경/취소·권한·중복 경로 확인 | 174개 모든 UI 상태 전수 검증 아님 |
| 개인 숨김·작성자 비공개 | A/B 구분·원문 제거·기존 대화 보존·새 방 제한 확인 | 재연결 시험과 실제 네트워크 장애를 구분 |
| AI·평가 | 실제 답변 저장/복원·평가·마지막 1회 동시 요청 확인 | 가상 입력 기술 시험, 실제 상담 효과 아님 |
| 운영자 | A가 유일한 운영자, 이전 가상 계정 역할 해제·계정 보존. B는 일반 계정 | A를 일반 사용자 권한 시험으로 사용하지 않음 |
| 기기 | Chrome 기기 모드 390×844·터치·저장 대화 복원 확인 | 실물 휴대폰·Safari로 확대하지 않음 |
| 계측 | 운영/QA 실제 수신, 개인정보 제외·동의/철회 확인 | 답변 분리 복원 이후 수신은 새로 확인 필요 |

## 이번 계측 변경의 확인 범위

- 지정된 기술 시험 세션에서 `?source=qa`로 구분합니다. 비밀번호·토큰·원문은 출력하지 않습니다.
- 정상 답변 완료 + 저장 실패 → 첫 답변 1, 저장 오류 1. 부분 실패 → 첫 답변 0. 정상 완료 + 저장 성공 → 첫 답변 중복 0, 저장 성공 1.
- 가상 스트림을 주입한 결과와 실제 공급자·DB 연동 결과를 따로 기록합니다. 실제 공급자·DB 장애를 일부러 발생시키지 않습니다.
- 이번 변경과 무관한 가입·메일·권한 이전·자정 차감 시험은 반복하지 않습니다. 기존 데이터·계정·문의는 보존합니다.
