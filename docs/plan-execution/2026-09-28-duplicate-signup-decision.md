# 기존 이메일로 다시 가입했을 때의 안내 — 판단 대기

2026-09-28 사용자 브라우저 관찰: 이미 가입한 이메일로 다시 가입을 시도하면 확인 메일이 새로 오지 않는데, 공개 화면은 메일 발송을 확정한 듯 안내했다. 이는 전달 문제로 단정할 수 없다. Supabase는 이메일 확인이 켜진 가입 요청에서 기존 계정 여부를 가리기 위해 성공처럼 보이는 응답을 줄 수 있다. 따라서 현재 `signUp()` 응답만으로 새 메일 발송 또는 중복 가입을 확정하지 않는다.

로컬 화면은 가입·재발송 결과를 **요청 접수**로 표현하고, 새 가입 대상 주소에만 메일이 도착할 수 있으며 기존 가입자는 로그인할 수 있다고 안내한다. 이 수정은 잘못된 성공 표현을 없애지만 **실제 중복 여부를 검사하지는 않는다**. 공개 앱에는 아직 배포하지 않았고 브라우저 재시험도 하지 않았다.

가입 화면에서 임의의 이메일 존재 여부를 즉시 알려주려면 서버가 관리자 권한으로 계정을 조회해야 한다. 그러면 누구나 다른 사람의 이메일이 니편내편에 가입돼 있는지 확인할 수 있다. 발송 제한만으로 이 정보 노출을 완전히 막을 수는 없다. 대안은 ① 첫 공개에서 중립 안내·로그인 경로를 유지하고 중복 여부는 밝히지 않기, ② 해당 이메일의 소유권을 메일 링크로 확인한 뒤 계정 상태에 맞는 다음 행동을 안내하기, ③ 즉시 중복 표시를 허용하고 노출 위험을 감수하기다. 이 정책은 사용자 선택 전까지 확정하거나 구현하지 않는다.
