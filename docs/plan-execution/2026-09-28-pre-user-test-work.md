# 실제 게시 전 작업 목록

최신 정책은 [PLAN](../../PLAN.md), 실행 상태는 [인수인계](README.md)입니다. 아래 PASS는 기록된 기술 범위이며 실제 이용자 만족도 증거가 아닙니다. [정리 전 원본](../../archive/2026-09-30/current-docs-before-cleanup/docs/plan-execution/2026-09-28-pre-user-test-work.md)의 과거 일부 PASS를 현재 대기로 사용하지 않습니다.

| 순서 | 작업 | 상태 | 근거와 남은 범위 |
| --- | --- | --- | --- |
| 1 | 환경·메일·인증 연결 | 기술 PASS | 지정 A/B 소유 확인·가입·분리 로그인, 공개 메일 복귀. 재설정 저장·재로그인은 사용자 보고 |
| 2 | 버튼의 정적 위치·계약 | 정적 PASS | 174개 고유 ID·계약 지도. 모든 조건부 상태 전수 PASS는 아님 |
| 3 | 사연·참여·권한 | 핵심 기술 PASS | 실제 시험 계정의 투표·댓글·공감·숨김/비공개·API 권한 확인 |
| 4 | AI 생성·저장·복원·평가 | 핵심 기술 PASS | 실제 포텐스 저장/복원·평가, 두 탭 마지막 1회, 삭제 후 횟수 유지 |
| 5 | 오류·조건부 동작 | 범위 한정 PASS | 주입 오류 뒤 실제 재시도, 문의 답변·닉네임·댓글·분석 철회·재연결·성인 보류·시험 계정 탈퇴 |
| 6 | 답변 완료·저장 결과 분리 계측 | 운영·범위 한정 PASS | 원래 합의 복원 배포. 가상 스트림 4종 집계·운영 GA4 수신 확인. 실제 공급자 재시험은 하지 않음 |
| 7 | 문서 정리·운영 반영 | 완료 | 원본 15개 보존·현재 안내 정리, fee5ea5 커밋·푸시, 운영 배포 READY·공개 번들 일치 |
| 8 | 운영 DB 직접 쓰기 차단 | 적용·기술 PASS | 정책 7개 차단·서버 저장 후속 확인. SQL 다시 적용하지 않음 |
| 9 | 공개 후 데이터·피드백 | 실제 이용 필요 | 커뮤니티·SNS 게시 → 처리 보고서 대조 → 근거 있는 첫 개선. 직접 모집·동석 관찰은 선행 조건 아님 |

자정 횟수 전환 확인은 사용자 요청으로 이번 범위에서 제외합니다. Chrome 기기 모드는 확인했지만 실물 Safari로 표기하지 않습니다. [검증 상세](2026-09-28-in-progress-release-preflight.md)를 따라 같은 시험을 불필요하게 반복하지 않습니다.
