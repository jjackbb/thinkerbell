앞서 확정한 다섯 규칙을 다시 묻지 않습니다. 아래는 로컬 작업 뒤 남은 정책·시험 준비 질문입니다. 추천은 미리 선택되어 있지 않습니다. 각 항목에서 고른 뒤 답변 복사를 눌러 채팅에 붙여 주세요. 비밀번호나 메일 주소는 적지 않아도 됩니다.

1. 작성자가 비공개로 바꾼 사연에 새 댓글을 달 수 있나요?

다른 사람은 신규 댓글을 달 수 없고 기존 댓글은 재공개까지 보존합니다. 작성자 자신의 새 댓글만 아직 결정되지 않았습니다.

2. 전환 전 AI 방의 옛 답변만으로 도움 평가를 열까요?

기존 저장 이력에는 정상 완료 표식이 없습니다. 현재 화면은 새로 정상 저장한 답변이 생기면 마무리 평가를 엽니다.

3. AI 대화 내용은 언제 자동 삭제할까요?

마이페이지의 ‘6개월 뒤 자동 삭제’ 문구는 실제 작업도 확정 정책도 없어 제거했습니다. 도움 평가의 30일 보관과는 별개입니다.

4. 도움 평가를 30일 뒤 어떤 집계로 남길까요?

하루·모드·점수별 1명 같은 셀은 이름이 없어도 이용자를 추정할 수 있습니다. 현재 일별 집계 SQL은 운영 적용 금지 초안입니다.

5. 버튼 분석은 어디까지 GA4로 보낼까요?

167곳은 정적 코드 위치 수입니다. 모든 버튼을 외부 분석에 보내는 것과 모든 버튼의 기능·실패 동작을 검증하는 것은 다릅니다.

6. 운영 시험용 새 메일함 두 개의 준비 상태

사용자가 직접 브라우저 로그인·인증을 하기로 한 결정은 유지합니다. 주소·비밀번호는 보내지 마세요.

이 화면에서 고르는 것만으로 제품 설정이나 운영 DB가 바뀌지 않습니다. 답변을 채팅에 보내 주시면 확인 후 진행합니다.
