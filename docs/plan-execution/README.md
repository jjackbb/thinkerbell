## 확정 정책과 작업 규칙

- 첫 AI 답변은 **정상 응답 완료**와 비어 있지 않은 표시 내용으로 집계한다. 저장 실패에도 답변 완료는 남기고 오류를 따로 센다. 차감과 평가 자격은 정상 저장 기준이다.
- 사용자 요청으로 커밋·푸시·운영 배포가 승인됐다. 기존 작업 브랜치를 사용하고 main 병합을 임의로 추가하지 않는다.
- 작은 가역 변경에 테스트를 새로 만들지 않는다. 이미 통과한 검사는 새 변경·문제 없이 반복하지 않는다.
- 불확실한 정책은 임의 확정하지 않는다. 마지막에 추천안·대안·기타 입력을 포함한 HTML로 한꺼번에 묻는다. 확정한 결정을 반복 질문하지 않는다.
- 지정 A는 운영자, B는 일반 시험 계정이다. 기존 계정·문의·보관 횟수를 보존한다. 비밀번호·메일 주소·토큰·사연 원문은 기록하지 않는다.
- Git 배포와 CLI 배포는 구분한다. 현재 운영 DB는 브라우저 직접 쓰기를 차단했으므로 옛 직접 쓰기 앱으로 단독 롤백하지 않는다.
