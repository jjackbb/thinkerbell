# 실시간 새로고침 후 내 투표 상태 보존

## 수정

공개 사연 데이터와 계정별 투표 표시를 분리했다. 공개 조회·실시간 갱신이 개인 선택이나 변경 여부를 지우지 않으며 목록과 상세에 동일한 투영을 적용한다. 계정 변경과 요청 순서를 확인해 늦은 읽기·쓰기 결과를 배제하고, 완료된 이전 요청이 새 요청의 진행 상태를 해제하지 않도록 했다. 같은 계정의 반복 인증 이벤트는 정상 진행 중인 요청을 무효화하지 않는다.

투표 권한·서버 원본·데이터베이스 정책은 변경하지 않는다. 개인정보 및 가입 안내 초안은 이 변경에 포함하지 않는다.

## 검증

기존 원격 코드에 이 수정만 적용한 별도 소스에서 다음 검사를 통과했다.

- 앱 TypeScript 검사와 빌드
- 브라우저 시험 fixture TypeScript 검사
- 비REST 단위 회귀 116개: 기존 103개와 신규 투표 투영 회귀 13개
- 변경 내용 공백 검사

신규 회귀는 공개 새로고침, 계정 전환, 늦은 응답, 확정된 투표 뒤 오래된 읽기, 반복 인증 이벤트와 요청별 진행 상태를 다룬다. 실제 데이터베이스·브라우저 CI 재실행과 운영 확인은 아직 대기 중이며, 단위 검사 통과를 운영 검증 완료로 표현하지 않는다.
