# 가입 확인 메일 한국어 문안 — 운영 미적용 초안

2026-09-26 사용자 시험에서 신규 가입→네이버 **받은편지함** 수신→앱 복귀 후 **로그인 유지**까지 확인됐다. 사용자는 받은 인증 메일 본문이 영어였다고 알리고 한국어로 바꿀 수 있는지 물었다. 이 문서는 [PLAN](../../PLAN.md)의 신규 가입 이메일 확인 메일만 다룬다.

## 변경안

- 제목: **[니편내편] 이메일 주소를 확인해 주세요**
- 본문: [confirm-signup.ko.html](../email-templates/confirm-signup.ko.html)
- 적용 대상: 니편내편 Supabase 프로젝트 `vzhyhadjtaqbapicjrco`의 **Authentication → Email Templates → Confirm sign up**. 비밀번호 재설정·초대·이메일 변경 메일은 건드리지 않는다.
- 작동 링크: Supabase 변수 `{{ .ConfirmationURL }}`을 그대로 사용한다. 정상 시험된 확인·앱 복귀 경로의 링크 방식을 임의로 변경하지 않는다.

현재 프로젝트의 운영 템플릿을 읽을 관리 권한이나 관리 API 토큰이 이 환경에 없어 기존 제목·본문을 대조하지 못했다. 따라서 파일은 **제안 문안일 뿐 운영 설정에 적용되지 않았다**. 기존 운영 템플릿의 제목·본문을 먼저 확인하고 차이를 검토한 뒤, [Supabase Email Templates](https://supabase.com/docs/guides/auth/auth-email-templates) 화면에서 제목과 본문을 저장해야 한다. Resend는 발송 경로이며 이 문구를 편집하는 곳은 Supabase다.

저장 후에는 본인이 관리하는 새 시험 주소로 가입해 **한국어 제목·본문 수신 → 링크 클릭 → 앱 복귀 → 로그인 유지**를 다시 확인한다. 이미 받은 영어 메일과 기존 계정은 바뀌지 않는다. 새 메일 시험을 완료하기 전에는 한국어 메일이 운영에서 전달된 것으로 기록하지 않는다.
