# 가입 확인 메일 한국어 문안 — 사용자 직접 수정 보고

2026-09-26 사용자 시험에서 신규 가입→네이버 **받은편지함** 수신→앱 복귀 후 **로그인 유지**까지 확인됐다. 사용자는 받은 인증 메일 본문이 영어였다고 알리고 한국어로 바꿀 수 있는지 물었다. 이 문서는 [PLAN](../../PLAN.md)의 신규 가입 이메일 확인 메일만 다룬다.

## 사용자에게서 받은 현재 변경 내용

- 사용자가 수정한 제목: **니편내편 이메일 주소 확인**
- 사용자가 수정한 본문: [confirm-signup.ko.html](../email-templates/confirm-signup.ko.html)의 HTML 조각. 초기 초안의 `<html>`·`<body>` 등 바깥 구조 없이 내용 부분을 직접 복사했다.
- 적용 대상: 니편내편 Supabase 프로젝트 `vzhyhadjtaqbapicjrco`의 **Authentication → Email Templates → Confirm sign up**. 비밀번호 재설정·초대·이메일 변경 메일은 건드리지 않는다.
- 작동 링크: Supabase 변수 `{{ .ConfirmationURL }}`을 그대로 사용한다. 정상 시험된 확인·앱 복귀 경로의 링크 방식을 임의로 변경하지 않는다.

수정 전 제목은 `Confirm your email address`, 본문은 기본 `<h2>`·설명·`{{ .ConfirmationURL }}` 링크의 영어 HTML이라고 사용자가 복사해 제공했다. [Supabase 공식 예시](https://supabase.com/docs/guides/auth/auth-email-templates)와 같은 구조이므로 별도 사용자 정의 동작은 제공된 내용에서 보이지 않는다. 사용자는 한국어 제목과 본문을 Supabase 화면에서 직접 수정했다고 알렸다. **저장 버튼 완료 여부와 새 메일 수신은 아직 별도 확인이 없다.** AI는 관리 화면을 직접 읽거나 변경하지 않았다. Resend는 발송 경로이며 문구 편집은 Supabase에서 한다.

사용자 메시지의 `\<h1>` 표기와 `&#x20;`는 채팅 복사 과정의 이스케이프/공백 표기일 수 있다. 실제 편집기에는 역슬래시 없는 `<h1>` 등 HTML 태그가 들어가야 한다. 저장 후 본인이 관리하는 새 시험 주소로 가입해 **한국어 제목·본문 수신 → 링크 클릭 → 앱 복귀 → 로그인 유지**를 확인한다. 이미 받은 영어 메일과 기존 계정은 바뀌지 않는다. 새 메일 시험을 완료하기 전에는 한국어 메일이 운영에서 전달된 것으로 기록하지 않는다.
