# UX 현재 기준과 후속 판단

[PLAN](../../PLAN.md)이 유일한 정책 기준입니다. [이전 질문·인터뷰 대조 원본](../../archive/2026-09-30/current-docs-before-cleanup/docs/release-improvement/04-ux-priorities-and-decisions.md)은 당시 기록이며 이미 해결한 항목을 다시 질문하지 않습니다.

| 우선순위 | 현재 기준 |
| --- | --- |
| 저장·등록 | 실제 서버 성공 후 완료 표시, 실패 초안 보존·재시도 |
| AI 발견·모드 이해 | 사연 상세에서 진입, 투표 필수 아님. 상대 역할/공감 대화 구분 |
| 답변·저장·복원 | 정상 완료와 저장 결과 분리, 부분 실패 제외, 저장 실패 미차감·새 답변 요청 |
| 마무리·도움 평가 | 대화 보존, 두 모드 정상 저장 답변 후 5점/건너뛰기, 점수 GA4 제외 |
| 개인 기록·권한 | 개인 숨김·작성자 비공개 분리, 작성한 사연 공개/비공개 구분·재공개 작성일 유지 |
| 운영·보류 | 실제 문의/신고 접수, 성인 기능 보류, 알림·구독 준비 중 |
| 공개 | 커뮤니티·SNS에서 자발적 이용 확인. 직접 모집·동석 관찰은 선행 조건 아님 |

## 이미 정한 사항

기존 의미 불명의 숨김 1건 삭제, 댓글 공감 숫자 0 초기화·계정당 1회/취소, 비공개 중 작성자도 새 댓글 불가, 기존 AI 대화 보존, 첫 공개 대화 자동 삭제 없음, 월 합계 최소 5명과 평가 30일 규칙은 확정했습니다. 계정/메일/GA4 소유 대상도 확인 기록이 있으므로 다시 선택을 요구하지 않습니다.

## 아직 실제 자료가 필요한 것

- 실제 소개 글의 게시 플랫폼·시각·주소.
- 공개 후 보고서·자발적 피드백과 근거 있는 첫 개선.
- 정확한 공급자 무료 종료일·일일 한도·사용량·도메인 영수증 등 미확인 운영 정보는 확인된 값처럼 쓰지 않습니다. 유료 전환은 자동으로 하지 않습니다.
- 과거 인터뷰의 날짜·참여 수·효과는 원본에 확인된 범위만 사용합니다. 과거 문제를 현재 재현된 결함으로 단정하지 않습니다.

제품 사용 경험을 바꾸는 추가 선택이 생기면 추천안·대안·기타 입력을 포함한 HTML로 한꺼번에 확인합니다. 기존 합의와 구현의 불일치는 사용자 결정에 맞춰 수정합니다.
