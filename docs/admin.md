## 운영 계정과 권한

2026-09-30 사용자의 명시적 승인으로 지정 A 네이버 계정에 운영 권한을 이전했습니다. 기존 가상 계정의 운영 역할은 해제했고 Auth 계정·기존 데이터는 보존했습니다. A가 유일한 운영자, B는 일반 시험 계정임을 확인한 기록이 있습니다. 이메일·비밀번호는 이 문서에 적지 않습니다.

마이페이지의 문의 관리에서 사용자 문의·AI 오류를 확인하고 답변합니다. 문의 저장·운영자 목록·답변 실패 뒤 실제 재시도와 B의 답변 확인이 기술 검증됐습니다. 운영 권한은 문의 처리 범위이며 타인의 AI 대화를 자유롭게 읽을 권한을 뜻하지 않습니다.

## 운영 원칙

- 사용자가 매일 신고·문의·AI 오류를 확인합니다. 접수 시각·처리 상태를 구분하고 사연·대화 원문을 외부 분석에 복사하지 않습니다.
- 문의 답변 저장이 실패하면 초안을 보존하고 실제 서버 성공 뒤 완료로 표시합니다.
- 과거 가상 계정으로 로그인·메일 재설정을 시도하지 않습니다. A의 비밀번호 재설정·새 비밀번호 로그인은 사용자 완료 보고가 있습니다.
- 담당자 변경·권한 이전은 대상과 영향 확인 후 진행합니다. 옛 SQL·과거 계정 기록을 현재 권한 변경 명령으로 실행하지 않습니다.
- QA 자료를 정리할 때 A/B 계정·운영 역할·보존된 문의·정상 횟수 기록을 유지합니다.
