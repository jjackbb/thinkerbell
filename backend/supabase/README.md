## 후속 작업

- 파일명에 draft가 있거나 예전 문서가 미적용이라고 적혀 있어도 SQL을 다시 실행하지 않습니다. 프로젝트·마이그레이션 이력·구조를 먼저 대조합니다.
- 운영 DB는 서버 쓰기 경로를 전제로 합니다. 구형 브라우저 직접 쓰기 앱만 되돌리거나 정책을 다시 열지 않습니다.
- Supabase CLI 작업 디렉터리는 `backend/`이며 로컬 임시 메타데이터 `.temp/`는 Git에서 제외합니다. 연결 정보·키를 문서화하지 않습니다.
- 이번 문서·계측 수정은 DB 변경을 포함하지 않습니다. 스키마 전체 일치나 보안 자문 무경고를 주장하지 않습니다.
