# ST4/ST5 — 감정 케어 마무리 경험 + 투표 결과 시각화

## 핵심 발견

- **감정 배출의 '마무리'는 "정리 → 다음 행동" 2단 구조.** Renée는 세션마다 `논의된 주제 / 감지된 감정 패턴 / 가지고 갈 한 문장(takeaway)` 3요소 therapy note를 자동 생성 (2026-08)
- **국내는 '보고서'로 마무리를 상품화.** 트로스트 AI 챗봇 '티티' 안에 `감정일기 / **마음정리보고서** / 감정스캐너` 병렬 배치
- **"끝났다"는 감각은 지연된 응답으로도 만들어진다.** LG유플러스 '답다': 감정 110여 개 중 택1 + 2,000자 일기 → **12시간 내** AI 답장. 가입자 1.3만(2024-01) → 8만(2025-01), 누적 일기 49만. 사진 첨부 후 체류시간 **+27%**
- **위기 UI의 핵심 지표는 "몇 탭 안에 닿는가".** Wysa 2탭(단 Safety Plan은 검색해야 노출), **Youper는 깨진 bitly 링크 / 위키피디아로 연결되는 치명적 실패**. 권고: 어느 화면에서든 **1~2 인터랙션 내 도달 + 오프라인 캐싱**. 전 앱 공통으로 오프라인 위기 자원 접근 전무 — Frontiers in Digital Health 2026 (A)
- **투표 결과를 미리 보여주면 다수 선택지가 평균 +7%p를 더 가져간다(밴드왜건).** — IJPOR 2020 (A)
- **다이버징(중앙 기준) 스택 바는 비율 표현에 비권장.** 100% 스택 바가 "양 끝 카테고리 비교"에 명확히 우월 — Datawrapper (A)
- **결과 공유는 카카오톡 1:1보다 네이티브 공유(플로팅바)가 10배 이상.** 푸망×W컨셉: 네이티브 9,793 vs 카톡 859 vs URL복사 639 (B)
- **소비자 AI 멘탈케어 앱은 죽고 있다.** Woebot 소비자 앱 2025-06-30 종료(사용자 150만), Youper 2026-09-30 종료. 이유는 효과가 아니라 **규제 대응 비용 + B2C 수익 한계**

## A파트: 감정 케어 마무리 설계

### 서비스별
- **Wysa**: 홈에서 바로 대화 → 앱이 먼저 **무드 체크인** 요청(스마일 슬라이더 + 이유 선택). 활동 단위가 Packs > exercises → **대화가 끝나는 게 아니라 '연습 1개 완료'로 종결**. ⚠️ 세션 종료 요약 카드 실물은 확인 못 함
- **Renée(2026)**: 마무리가 가장 명시적. therapy notes 3요소 + Guided Journal 4종. **반응형이 아닌 선제형**(앱을 열지 않아도 맞춤 check-in 발송)
- **트로스트**: **"감정 한 컷"** — 오늘의 기분을 사진처럼 찍고 스티커·텍스트로 꾸미기 → 기록을 **꾸미기 가능한 오브젝트**로 만들어 완료감 생성
- **마인디**: 채팅형 일기 → **"분석하기"** 버튼으로 사건/생각/감정 3분할(REBT). **월간 리포트**를 캐릭터로 시각화. "완성된 나의 자서전" 프레이밍
- **답다(LGU+)**: **지연된 마무리** — 즉답이 아니라 12시간 후 답장. 배출 직후 종결시키지 않고 재방문 훅을 심음
- **Teeni**: **Quick Relief → "Hot Flow"(음성 즉시 배출) → 방출 후에야 "Cold Flow"(성찰)** — 배출과 성찰을 분리된 2단계로
- **Headspace(반례)**: Pratt 크리틱 — *"세션이 끝난 후 너무 빨리 다음으로 넘어간다. 'How did that feel?' 같은 짧은 성찰 프롬프트를 넣으면 정서적 몰입이 깊어질 것."* 현재는 완료 애니메이션+체크마크+스트릭만

### 이론적 근거
- **Peak-End Rule**(Kahneman): 경험 평가는 '정점'과 '끝'으로 결정, 지속 시간은 영향 없음
- **NFCC(인지적 종결 욕구)**: 인간은 모호함을 피하고 확정적 답을 찾음
- 경고: **"과업 완료를 종결로 오인하지 말 것"** — UX Magazine

### 요약 카드 구성 요소 (빈도순)
대화 주제 요약 / 감정 패턴 / **한 문장 takeaway** / 사건·생각·감정 3분할 / 월간 리포트 + 캐릭터 / 임상 척도 추이 / AI의 답장 / 명명된 보고서

### 위기 대응 (국내 사실관계)
- **자살예방상담전화 = 109** (2024-01-01 통합, 24시간 익명·비밀보장). 채널: **전화 / 문자 / 카카오톡 / 앱 '마들랜'**
- 정신건강위기상담 1577-0199
- 국내 사업자 의무: **KISO 정책규정 제2절 '자살예방을 위한 정책'**. 카카오는 머신러닝 자동 감지 + 운영자 검토
- **다음뉴스는 2023-09-06부터 자살 관련 보도 클릭 시 기사 원문보다 먼저 주의 안내문을 노출** ← 익명 사연 서비스에 그대로 이식 가능한 인터스티셜 패턴
- 설계 원칙: 위기 활성화 시 **다른 내비게이션을 전부 제거**하고 안전에만 집중

### 리텐션 & 스트릭 경고
- Calm: 활동 시작 **전** 무드 체크인 프롬프트, 체크인 4분류(Mood/Sleep/Gratitude/Mindfulness), **스트릭 세이프티넷**(끊겨도 History 편집으로 복구)
- **Bear Room: 3일 단위 짧은 스트릭. 하루 빠져도 리셋 안 되고 3일마다 작은 보상.** "부재를 처벌하지 않고 복귀를 부드럽게 지원"
- ⚠️ **두 독립 출처가 감정 케어 맥락의 스트릭을 경고**: Smashing("지지가 아니라 압박"), Pratt("'기분이 나아지려고' → '숫자를 지키려고'로 개념 모델이 변질"). 개선안: **스트릭을 기본 노출이 아니라 요청 시 노출**

## B파트: 이지선다 결과 시각화 패턴 카탈로그

| # | 패턴 | 형태 | 적합 상황 | 사례 |
|---|---|---|---|---|
| 1 | **100% 가로 스택 바** | 하나의 바를 A/B로 좌우 분할 | 비율 비교가 핵심. **양 끝 비교에 가장 우월** | Datawrapper 권장 |
| 2 | 분할 바(split) | A/B 별도 바, 각자 기준선 | 긴 레이블·아이콘이 붙을 때 | Datawrapper |
| 3 | **옵션 카드 배경 채움** | 선택지 텍스트 행 자체가 진행바로 채워짐, 우승은 볼드 | 모바일 피드에서 세로 공간이 좁을 때 | X(Twitter) |
| 4 | 도넛/파이 | 원형 2분할 | 카드형 결과 이미지 | Mentimeter |
| 5 | **닷(unit) 차트** | 표 1개 = 점 1개 | **표본이 적을 때 유리** | Mentimeter Dots, Flourish |
| 6 | 다이버징 스택 바 | 중앙 baseline 좌우 | 리커트 척도용. **2지선다엔 비권장** | Datawrapper 명시적 비권장 |
| 7 | 게이지/니들 | 반원 게이지 바늘 | 우세감 극적 전달, 실시간 변동 | NYT election needle |
| 8 | 스윙 화살표 | 이전 대비 변화량 | 시간에 따른 여론 이동 | Flourish |
| 9 | 줄다리기/저울(은유) | 중앙 경계가 우세쪽으로 밀림 | 대결 프레이밍이 본질일 때 | ⚠️ Figma 템플릿만 확인, **프로덕션 사례 미확인** |
| 10 | **다수파/소수파 판정 문장** | 비율 대신 "당신은 소수파" 판정 | 정체성 피드백이 목적 | 밸런스픽 |
| 11 | 실시간 동시 공개 | 전원 투표 후 동시 공개 | 소규모 그룹, 동시성이 재미 | '둘 중 하나' |

### 설계 규칙 (Datawrapper)
- 가장 중요한 값을 baseline에 두고 색으로 강조
- **100% 스택은 좌·우 두 개의 기준선을 얻는다** → 이지선다는 두 선택지 모두 기준선을 갖는 이상적 케이스
- 부분이 하나의 총계뿐이면 세로 컬럼보다 **가로 바**가 공간 효율이 좋다
- "한 총계의 한 비율만 전달할 거면 차트가 필요한지 다시 생각하고 텍스트로 쓰라"

### 투표 전/후 전환
- **Instagram**: 투표 전 결과 비공개. 투표 후 viewer는 **퍼센트만**, 작성자만 위로 스와이프해 **투표수 + 투표자 실명** 확인
- **X**: 투표 후 즉시 막대 + %, 우승 볼드, 하단에 **총 투표수와 남은 시간**
- **Slido**: 결과 표시/숨김, 투표 카운터 숨김, 투표 잠금을 각각 별도 설정
- 애니메이션: 오버슈트 스프링 `cubic-bezier(0.34, 1.56, 0.64, 1)`가 마이크로인터랙션 표준

### 결과 공유 (푸망×W컨셉 실측, 2주)
| 지표 | 값 |
|---|---|
| 2주 플레이 | 177,390회 |
| 단계별 이탈률 | 전 구간 3% 미만 |
| 광고 CTR | 8.6% (플랫폼 평균 3~5%) |
| **네이티브 공유(플로팅바)** | **9,793회** |
| 카카오톡 공유 | 859회 |
| URL 복사 | 639회 |

- 결과 카드 = 캐릭터 일러스트 + 성격 키워드 + 광고 배너
- **공유율 1위 유형과 광고 CTR 1위 유형이 서로 다름** → "확산시킬 유형"과 "전환시킬 유형"을 분리 설계 가능
- **Instagram "Share Results"**: 원본 스토리를 복제하고 투표 스티커 자리에 결과 %를 얹은 이미지 자동 생성 → **"결과 카드 = 원본 콘텐츠 + 수치 오버레이"** 재사용 가능 패턴

### 표본이 적을 때
- 퍼센트는 어떤 표본에서도 계산되지만 **작은 표본의 점추정치는 거의 확실히 틀리다** — MeasuringU
- 권고: ① **퍼센트와 원시 비율(3/7)을 함께 표기** ② **소수점 쓰지 않기**(42.86% ❌ → 43% ✅) ③ 가능하면 신뢰구간
- 여론조사 관행: 보고 가능한 최소 표본 100명(이때도 오차 ±10%p)
- ⚠️ **"N 미만이면 % 숨김" 임계값 UI를 구현한 상용 사례를 찾지 못함.** Instagram·X·Slido 모두 **"투표 전 숨김 / 투표 후 공개"라는 이진 규칙**

## 니편내편 적용 제안 (에이전트 원안)

1. **현재의 가로 스택 바는 옳은 선택.** 개선은 형태가 아니라 **바 위에 무엇을 얹느냐**: 우세 선택지 볼드 + **총 투표수 병기** + **소수점 제거** + **"내 편 62% (31표 / 50표)"처럼 원시 수 병기**. 다이버징으로 바꾸는 유혹은 참을 것
2. **'다수파/소수파 판정 문장' 추가** — 비율보다 정체성이 공유를 만든다. "당신은 이 사연에서 소수 의견입니다 (23%)". 사연 투표는 원래 "내가 이상한 건가?"를 확인하러 오는 행동이므로 정합적
3. **'감정 해소 완료 팝업'을 요약 카드로 승격** (Peak-End Rule). Renée 3요소 + **니편내편 고유의 4번째 요소: "당신 편에 선 사람 N명"** ← 다른 감정 케어 앱이 가질 수 없는 자산
4. **마무리 카드를 그대로 공유 카드로** (Instagram Share Results 패턴). 배치는 **하단 고정 플로팅바 + OS 네이티브 공유시트** (카톡 버튼 상단 배치보다 10배 효율). 익명이므로 **캡처해도 신원이 안 드러나는 카드 디자인**이 전제
5. **투표 전 은닉 유지**(밴드왜건 +7%p는 실측). 표본이 적을 땐 숨기지 말고 **닷(unit) 표시로 전환** — 5명이면 점 5개. "아직 5명이 투표했어요"
6. **위기 대응이 가장 시급.** 109 하드코딩 + 오프라인 동작 + 1~2탭 도달 + 위기 화면에서 다른 내비 제거 + KISO 제2절 점검 + **다음뉴스식 인터스티셜**(본문보다 먼저 주의 안내)
7. **스트릭을 넣는다면 Bear Room 방식**(3일 단위, 하루 빠져도 리셋 없음) 또는 Calm 세이프티넷. 그리고 **기본 노출이 아니라 요청 시 노출**
8. **시장 신호**: 소비자 AI 멘탈케어는 규제·수익 문제로 죽고 있다. 니편내편이 '치료'가 아니라 **'또래 의견 + 감정 해소'** 포지션을 유지하는 게 유리
