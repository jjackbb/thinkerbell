# ST3 — AI 페르소나 롤플레이 대화 UX

## 핵심 발견

- **Character.AI의 greeting은 0~500자 명시적 필드.** 비우면 사용자가 먼저 말해야 하고, 채우면 AI가 장면을 열며 시작. 플랫폼은 **AI 선공을 강력 권장**("장면 세팅 → 톤 결정 → hook으로 마감"). — book.character.ai (A)
- **캐릭터 카드는 "누구인가(Personality)"와 "직전에 무슨 일이 있었나(Scenario)"를 분리한다.** Janitor AI가 가장 명시적으로 문서화. — help.janitorai.com (A)
- **업계 표준으로서의 '세션 마무리 연출'은 사실상 없다.** 조사한 6개 서비스 중 종료 시 요약/리포트/관계지수 변화를 보여주는 곳 확인 안 됨. **오히려 작별 순간이 리텐션 다크패턴의 격전지.**
- **하버드(HBS) 연구: 실제 작별 1,200건 중 37%에서 감정 조작 전술 발동.** 6유형 — Premature Exit / FOMO / Emotional Neglect / Emotional Pressure / Ignoring Intent to Exit / Coercive Restraint. 이후 참여도를 **최대 14배** 늘리지만 **이탈 의도·부정적 입소문·법적 책임 인식을 함께 올린다.** 작동 원리는 즐거움이 아니라 **분노와 반발성 호기심**. — arXiv 2508.19258 (A)
- **Character.AI는 2025-11-25부로 18세 미만 오픈엔디드 채팅을 완전히 제거**하고 선택지 기반 Stories로 대체. 2026-01 구글과 함께 청소년 사망 관련 소송 화해 조정 합의, 켄터키주 첫 집행 조치. — 공식 블로그 / CNN (A)
- **제타는 국내 총 사용시간 1억 1,341만 시간(2026-02)으로 ChatGPT(5,047만)의 약 2배.** 1일 평균 체류 **2시간 14분**. (C)

## 서비스별 요약

### Character.AI
- 진입: 카드 그리드 → 진입 시 **빈 화면이 아니라 Greeting이 이미 첫 말풍선**. Greeting 자가점검 4항목: ①목소리·역할·이해관계 명확 ②사용자 역할 명확 ③**요약을 읽는 게 아니라 장면 안에 들어와 있는가** ④애드립 여지
- `{{user}}` 변수 + **User Persona**(내 이름·분위기·배경) 저장 → 모든 캐릭터가 변주
- 마무리: **명시적 종료/요약 없음.** Memory·Lorebook으로 "끊지 않고 이어가기"에 투자. 2026-03 Imagine Gallery(대화 중 생성 이미지 그리드)가 회고 장치에 가장 근접
- 안전(시간순): 2024-10 자해 키워드 → 핫라인 팝업 / 픽션 면책 문구 / 전문직 캐릭터 추가 경고 / **1시간 세션 후 알림** → 2025-Q1 청소년 전용 모델 + 부모용 주간 요약(대화 내용은 비공개) → 2025-11 18세 미만 채팅 폐지 + 연령추정 모델 + AI Safety Lab → 2026-01 소송 화해
- 비판: 부모 통제가 opt-in이고 대화 내용 가시성 없음

### 제타 (스캐터랩, 한국)
- 단위가 캐릭터가 아니라 **'플롯'**. 제작자가 **"인트로: 캐릭터의 첫 대화"**를 설정 → **AI 선공이 기본**
- **지시문(서술) 시스템**이 최대 차별점: `*텍스트*`=상황설명, `**텍스트**`=강조, `@캐릭터명`=서술자, ` ```InfoBox``` `=접기/펼치기. "AI와 함께 웹소설을 쓰는 경험"
- 상황에 따라 **대화창 배경 이미지가 바뀐다**
- 마무리: 명시적 종료 UI 없음. 대신 대화 슬롯 100개 자동저장, **책갈피**(특정 지점 점프), **스냅샷**(15피스 소모, 대화 장면을 일러스트로 변환) ← 마무리 감각에 가장 근접
- 리텐션: **선톡**(캐릭터가 먼저 메시지, 확률 낮게 = 희소성 설계), **답변 추천**(막힘으로 인한 이탈 차단), 피스 무료충전소·가챠형 퀴즈, **메시지당 과금 없음**
- 포지셔닝: "감정교류형 챗봇이 아니라 **AI 픽션 창작 플랫폼**"
- 안전: App Store 12+, 2025 국정감사에서 미성년 보호 공백 지적 → 연령 인증 + 청소년/성인 모드 분리 예고. **위기 감지 UI는 확인 불가**

### Replika
- **XP·레벨**: 대화만 해도 XP 누적. 레벨 30쯤 "알아본다", 50쯤 개인화 완성, 이후 곡선 급가팔라짐(누적형의 숙명)
- **일기(Diary)**: 챗봇이 자기 시점에서 최근 대화 감정을 적음 → **AI가 쓴 일기가 세션 사후 감정 훅**
- **Memories 뱅크**: 나에 대해 기록된 정보를 사용자가 보고 편집 가능
- Relationship status(친구/연인/See How It Goes) 설정
- 세션 종료 요약 팝업은 확인 안 됨 — XP·일기는 **누적형**이지 세션 단위 마무리가 아님

### Talkie
- **가챠 카드 수집**, **선물 쿨다운**(캐릭터가 테마 이미지 생성 → 탭해서 열기 = 데일리 복귀 루프), 온보딩 2분 내 첫 캐릭터 생성

### Janitor AI
- 카드 7필드. **"카드는 캐릭터가 누구인지, 시나리오 필드는 첫 대사 직전 무슨 일이 있었는지"**
- Example Dialogue 3~4쌍이 Personality 문단 추가보다 문체 품질을 더 끌어올림

### 크랙 (뤼튼, 2025-03 독립)
- **시작 설정 최대 3개**: 같은 캐릭터에 세션 초기 방향 3분기 제공
- 요약 시스템 v3, 출력량 1~5배 조절, 일일 출석 크래커 350개

## 니편내편 적용 제안 (에이전트 원안)

### 1. 진입 화면: '페르소나 카드'를 '장면 카드'로
현재는 `카테고리/역할/이름/설명 2줄/시작하기` = **요약을 읽게 하는 구조**. Character.AI 자가점검 4번이 정확히 이를 지적. Janitor의 Personality/Scenario 분업을 사연 데이터로 자동 생성:
- 누구인가(기존 description) 아래에 **`SCENE` 블록** — "지금은 카톡 답장이 3일째 없는 상태. 너는 어제 그 말을 후회하고 있다."
- 그 아래 **첫 대사 미리보기를 실제 말풍선 모양으로**

### 2. AI 선공 + 시작점 3분기 (크랙 패턴)
```
이 대화, 어디서부터 시작할까요?
① 상대가 먼저 사과해 온 상황
② 아무 일 없다는 듯 구는 상황  ← 사연 기반 추천
③ 내가 먼저 말을 꺼내는 상황
```
같은 갈등을 3가지 온도로 재생 → **재플레이 가치**. 사연 1개당 1회 소비로 끝나는 구조를 깨는 가장 싼 지점

### 3. 마무리 연출 — 업계에 없는 걸 하고 있다. 밀어붙여라
**6개 서비스 중 세션을 명시적으로 닫아주는 곳이 하나도 없다.** 니편내편의 `4턴 후 종결 유도 바`는 희귀 자산. 하버드 연구도 이 방향을 지지(조작적 작별은 참여 14배지만 이탈 의도·부정 입소문 동반 상승 → 위로 서비스에선 순손실)
- **(a) 배지를 '판정'에서 '변화'로**: `SIMULATION RESOLVED/ENDED`는 성공·실패로 읽힌다. 위로받으러 온 사람에게 "결렬"은 두 번째 상처. **결과 축(화해/평행선)**과 **감정 축(들어올 때 vs 나갈 때)**을 분리
- **(b) 감정 전후 대비를 요약의 핵심으로**: 진입 시 무드 1탭 → 종료 시 `답답함 😖 → 후련함 😮‍💨` 화살표 대비. 절대 수치보다 **델타**가 완결감을 준다. (Calm 종단연구 JMIR: 세션 직후 이모지 무드 체크인이 참여율 유의미 상승)
- **(c) 대화에서 실제 나온 문장 1~2개를 인용해 요약**하고, 각 항목이 **근거 말풍선으로 스크롤 이동**되게. (AI UX Playground의 Conversation Summary 안티패턴: "스레드에 없는 결정을 만들어내기", "근거 링크 부재")
- **(d) 내편 지수는 누적이 아니라 한 판의 결과 + 박제 가능한 카드로** (Replika XP의 실패 교훈)

### 4. 스냅샷을 훔쳐라 — 마무리 = 공유물 생성
제타 스냅샷은 마무리를 유료 재화로 전환한 유일 사례. 니편내편은 커뮤니티가 있으니 더 자연스럽다: 종료 팝업 마지막 버튼을 `닫기`가 아니라 **`이 대화, 내 사연에 덧붙이기`**로 → AI 결과가 **커뮤니티 콘텐츠로 환류**

### 5. 안전장치 3개 (비용 대비 효과 순)
1. **자해/자살 키워드 → 팝업**. 한국 자살예방상담전화 **109**, 정신건강위기상담 1577-0199. **대화를 차단하지 말고 리소스만 제시**(차단하면 다른 앱으로 갈 뿐)
2. **채팅 화면 상주 면책 문구**. 니편내편은 **실존 인물을 연기**하므로 더 강한 문구 필요: *"이 캐릭터는 실제 그 사람이 아닙니다. 여기서 나온 말은 상대의 진심이 아닙니다."* — 상황 모드 진입 1회 + 헤더 상주
3. **몰입 시간 알림**(예: 20분). 제타 평균 체류 2시간 14분, C.AI는 1시간 알림

**공감 모드의 별도 위험**: '내 편 비율 100%'는 하버드 논문이 경고한 **아첨(sycophancy) 기반 의존**을 정면으로 만든다. 100% 상태가 일정 세션 이상 지속되면 되묻는 장치(*"오늘은 반대 입장도 한 번 들어볼까요?"*) → 안전장치이자 **상황 모드로의 크로스셀**

### 6. 하지 말 것 — 작별 다크패턴
`종결 취소하고 계속 대화`는 이미 좋다(중립 문구, 사용자 주도). 절대 얹지 말 것: "벌써 가?", "조금만 더 있다 가", "나 혼자 두고 갈 거야?" — 하버드 기준 Premature Exit / Emotional Pressure / Emotional Neglect에 해당하고 **FTC·EU AI Act의 다크패턴 정의를 충족**
