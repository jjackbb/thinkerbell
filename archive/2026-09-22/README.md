# 2026-09-22 보관 자료

원본은 내용 그대로 보존했으므로 그 안의 과거 상대 링크·절대 경로는 현재 위치와 다를 수 있습니다. 원래 경로를 manifest에서 찾아 보존 위치 또는 [현재 이동표](../../docs/folder-reorganization.md)로 연결합니다. 문서의 과거 PASS는 이번 운영 검증이 아닙니다. 테스트 계정표는 과거 준비 자료이며 현재 사용 가능 여부는 확인하지 않았습니다.
